# Smart Attendance Manager

A modern attendance management system with the following capabilities:

- Title changed to Smart Attendance Manager
- Problem statement and solution overview added to the dashboard
- New timetable page added for weekly class schedules
- Login system added to secure access
- Student management, attendance, and reports
- Node.js backend scaffold included (`server.js`)

## Features

- Dashboard with attendance overview, weekly attendance chart, and recent activity
- Student CRUD with search and status tracking
- Attendance marking per date and class filter
- Reports page with attendance percentage and grade
- Timetable page for weekly class planning
- Simple login screen with persistent logged-in state

## Node Backend

A basic Node.js/Express backend scaffold is included:

- `package.json`
- `server.js`

Start the backend with:

```bash
npm install
npm start
```

Then open `AMS.html` in a browser or use the server static files directly at `http://localhost:3000`.
